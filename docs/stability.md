# 稳定性验收与限流

## 本轮交付

鉴权与会话权限按用户要求延期；当前仍是本机单用户服务。

1. Gateway 共享全局请求额度，每个 WebSocket 另有连接额度；新发送和新引导共用会话额度，重连不重置会话额度。相同请求 ID 重发不重复创建 Run、不重复扣会话额度，但仍计入 RPC 请求额度。
2. 一个模型 Runtime 共享每分钟调用额度和活跃 HTTP 请求上限。普通问答、工具后续、摘要和引用修正都计入实际 HTTP 调用数。审批等待期间释放 HTTP 名额；异常、取消和消费结束均释放名额。
3. 停止任务、拒绝工具绕过请求频率限制，保留中止入口；仍执行原有参数和状态校验。
4. 统一验收报告包含源码与 fixture 指纹、Node/平台、重复轮次、每项状态、耗时和失败原因。重点场景额外保存输入、配置、预期、实际与 Trace；其余回归明确标记“仅断言记录”。
5. 模型 HTTP 错误不记录服务商正文；传输和读取异常不保存原异常及原因链，避免接口诊断信息泄露密钥。
6. Web 顶部「验收报告」读取最新报告，可展开逐轮证据，也可查看当前限流配置和计数。HotpotQA 的真实模型质量评测保留在原「评测」入口。

## 重复运行

在项目目录执行：

```sh
pnpm verify --repeat 2
```

重复次数 1–10，默认 1。每轮使用独立测试进程、临时 SQLite 和受控模型响应，不加载用户 `.env`，不调用真实模型。测试包含真实本机 WebSocket、实际工作区文件写入、真实子进程 SIGKILL，以及受控网络错误和取消注入。

结果保存到 `.data/verification/latest.json`，另存带时间戳历史文件。测试失败、环境阻塞、跳过、缺轮分别显示；任何一项未全部通过，命令退出码为 1。断言错误保留原始失败信息。验收期间修改源码会中止报告生成，避免指纹和执行版本不一致。报告只保存测试 fixture 和测试 Trace，不保存 `.env` 或实际模型密钥；实际对话日志仍可能含用户内容，沿用本机存储边界。

这份报告验证工程行为，不证明真实模型答案正确率，也不代表生产高并发吞吐量。鉴权、跨实例共享额度、持久化额度、生产压测及完整 OS/网络代码隔离尚未完成。

## 默认配置

修改环境配置后重启服务生效。实现是令牌桶：按时间连续补充额度，可先突发到 burst 上限；不是严格滚动一分钟计数。

| 层级 | 补充额度/分钟 | 突发上限 | 并发上限 |
| --- | ---: | ---: | ---: |
| 模型 HTTP | 60 | 12 | 4 |
| Gateway 全局 | 600 | 100 | — |
| 单连接 RPC | 120 | 40 | — |
| 单会话新发送/引导 | 20 | 8 | — |

环境变量见 `.env.example`：`MODEL_REQUESTS_PER_MINUTE`、`MODEL_REQUEST_BURST`、`MODEL_MAX_CONCURRENT`；`GATEWAY_REQUESTS_PER_MINUTE`、`GATEWAY_BURST`；`CONNECTION_REQUESTS_PER_MINUTE`、`CONNECTION_BURST`；`SESSION_SENDS_PER_MINUTE`、`SESSION_SEND_BURST`。限流不自动重试；频率错误带 `retryAfterMs`。模型并发满返回 `MODEL_BUSY`；本地模型频率满返回 `MODEL_RATE_LIMITED`；服务商 HTTP 429 返回 `PROVIDER_RATE_LIMITED`。失败码保存在 Run 事件中。

额度和计数只在进程内生效，重启清零；单进程共享，未接 Redis。Gateway 全局桶计入合法协议请求的尝试数，连接桶拒绝的请求也已计入全局桶。模型桶只在真正准备发 HTTP 请求时扣额度；已发出的失败调用也计入额度。限流抑制请求增长，不能替代按实际 token 和价格计算的账单预算。

## 用户参与验收

1. 重启服务（`pnpm dev`）并刷新页面，点击顶部「验收报告」。确认显示重复轮数和失败/阻塞数量。
2. 打开 `Gateway session quota...` 场景，展开输入、实际与 Trace，核对重发只产生一个 Run，重连后新发送被限流。
3. 打开 `SIGKILL after a real file commit...`，确认实际文件存在、工具状态 `unknown`、待执行数 0，没有自动重放写入。
4. 打开 `model concurrency...`，确认超额请求没有进入 HTTP；取消和传输失败后活跃数回到 0。

页面查看只读取报告和计数，不启动测试、不请求模型。页面交互验收与自动报告的状态分别记录，不能用自动通过代替用户确认。
