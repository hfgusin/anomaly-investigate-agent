# search_workspace：共同验收清单

`search_workspace(query)` 只搜索 `workspace/` 下普通 UTF-8 文本，返回路径、行号和不超过 240 字符的匹配片段；不会把整份文件交给模型。

| ID | 用户操作 | 页面预期 | 记录预期 |
|---|---|---|---|
| SW-1 | 请求搜索 `Cedar-731`，点允许 | 最终回答命中 `agent_demo.txt` 及行号 | `search_workspace` 参数只有 `query`，结果含一条路径、行号和短片段 |
| SW-2 | 同一请求，点拒绝 | 模型说明无法搜索 | 状态 `rejected`，结果没有搜索片段 |
| SW-3 | 搜索不存在的词，点允许 | 模型说明无匹配 | `matches: []`，工具仍是 `completed` |

完成记录：SW-1 由用户在真实接口下完成；SW-2、SW-3 在当前真实接口下由 agent 自测完成。SW-2 最初暴露“拒绝被说成无匹配”的缺陷，已改为运行时对全拒绝轮次输出事实回答；`pnpm test` 的 27 项检查覆盖该回归与搜索边界。
