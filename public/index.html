Agent 配置

连接你的模型

在项目目录复制 .env.example 为 .env，填写已有接口的信息，然后重启服务。方舟内置联网选择 responses；普通兼容接口选择 chat-completions。

MIRROR_RUNTIME=responses
MODEL_BASE_URL=你的 API 根地址
MODEL_NAME=你的模型 ID
MODEL_API_KEY=你的密钥

Base URL 应包含服务商要求的版本路径，程序会追加 /chat/completions。密钥仅由本机后端读取。

保持 MIRROR_RUNTIME=demo 可以体验会话流程，演示模式不会调用模型。
