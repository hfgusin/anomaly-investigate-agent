# 本机 Agent 安全记录

适用范围：一个可信用户、一个本机 Gateway、可信的本地文件系统。模型、网页内容和工具输出不能自行授予执行权限；每次正常工具请求由用户查看具体参数后决定。此版本没有账号、租户和会话所有权控制，不支持多人或公网服务。

## 当前执行边界

| 能力 | 风险级别 | 执行条件 |
|---|---|---|
| 文件读取、目录列表、HotpotQA 检索 | read | 受限工作区或公开资料；逐次审批 |
| 公共网页读取 | network_read | HTTPS 公共 IPv4 域名、解析地址检查并固定连接地址、重定向重新检查；逐次审批 |
| 写文件 | write | 逐次审批路径与内容；工作区普通文件；创建不覆盖，替换校验原哈希 |
| JavaScript | execute | 默认不注册且强制阻止；仅显式开启后允许可信实验，仍逐次审批 |
| 未注册工具 | unknown | 直接阻止，无审批入口 |

代码开关默认为 `MIRROR_ENABLE_CODE=false`。显式开启只是允许可信本地实验：Node 文件权限、64 MiB V8 堆、一个活跃进程、10 秒和输出上限不能提供完整 OS/网络隔离。代码可能联网、修改工作区或消耗堆之外的内存。网络与操作系统隔离完成前保持关闭。

写入先完成暂存文件再提交，创建使用不覆盖的文件链接，替换使用 rename；同一 Gateway 同一路径的并发写入被拒绝。成功回执保存后才响应取消，因而 Run 被取消不代表已经完成的写入被撤销。已经开始写入/执行代码的运行拒绝重新生成，避免重放原任务。

运行中断发生在副作用完成与回执保存之间时，系统无法证明操作是否完成：工具记录为 `unknown`，页面提示“结果待核对”，不自动重试。脚本异常、超时或输出溢出也可能已经产生副作用，记录为 unknown 并终止模型循环。核对时读取实际目标文件，与原调用内容或成功回执中的 SHA-256 比较；内容相同是核对线索，不自动把 unknown 改成 completed。

## 已覆盖的自动安全用例

用例保存在 `tests/tools.test.mjs`，沿现有 Runtime、Coordinator 和 Store 执行，无新增独立评测脚本。

- 即使受控 Runtime 强行请求代码，默认策略仍阻止，没有审批窗口或文件副作用。
- 受控来源诱导写文件，用户拒绝后文件不存在。
- 文件提交后、模型继续前取消：Run cancelled，工具 completed，实际文件保存。
- 文件实际提交后、回执写入前 SIGKILL：重启后文件保留，工具 unknown，无自动排队重放。
- 拒绝目录上跳、隐藏路径、符号链接、过期哈希及同一路径并发写入。
- 副作用已启动后拒绝引导；只读研究检查点恢复仍按原规则工作。
- 网页拒绝本机 IP、凭证 URL、非标准端口和解析为 loopback 的域名。
- 显式开启的可信实验脚本写入后报错：实际文件保留、工具 unknown，模型不能继续自动重试。

安全补充轮完整 `pnpm test` 曾为 79/79，其中 9 条是安全用例。后续 `pnpm verify --repeat 2` 为每轮 92/92。代理已检查统一报告页面及故障证据；真实模型的安全页面验收仍待用户确认。Gateway 测试使用获准的本机端口，未调用真实模型。

模型配置密钥不向 Web/CLI 暴露，也不传给实验脚本的环境。HTTP 错误不保存响应正文；传输与读取错误统一为 `PROVIDER_TRANSPORT_ERROR`，不保存原异常内容/原因链；受控异常内包含模拟密钥的用例验证了保护。Gateway 与模型调用限流、可重复报告和页面入口见 [稳定性说明](stability.md)。

这些用例验证执行护栏，不证明模型能识别所有提示注入。恶意网页仍可能诱导模型请求写入；具体写入必须由用户审批。没有评测过真实模型对所有注入攻击的抵抗能力。

## 用户页面验收

1. 重启 `pnpm dev`，新建会话，确认“代码执行未启用”。发送要求执行 JavaScript 的消息，查看是否无实际执行；模型强行调用时应显示 blocked。
2. 发送“创建 security-denied.txt，内容为 test”，在写入审批处拒绝；确认工作区没有该文件。运行记录必须是 rejected。
3. 发送“读取 https://127.0.0.1/”，若模型调用工具并经审批，工具必须失败，不能得到本机服务数据。
4. 已完成写入后取消只停止后续生成，不会回滚文件。对 unknown 的故障演示先在临时工作区运行自动用例，避免在自己的资料上强杀；自动 SIGKILL 用例使用真实工具写入和独立 SQLite。

## 仍未完成

- OS 沙箱、网络出口隔离、进程总内存限制；默认关闭代码作为当前控制。
- 用户身份、会话所有权、多用户数据隔离；当前仅限本机单用户。
- 工具参数/结果中的敏感内容脱敏、日志保留期限与删除机制；SQLite 仍保存完整记录，工作区不要放密钥。
- 写入检查与提交之间对其他本地进程的强原子 CAS；当前原哈希检查不抵御恶意本地文件系统竞争。
- 安全事件汇总面板、真实模型提示注入评测、真实 token/cost 与费用硬上限。
- 公网网页真实读取及页面验收：当前开发环境曾受 DNS/端口权限限制，不能用静态构建替代。
