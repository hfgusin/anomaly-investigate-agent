## 恢复与边界

存档压缩包包含源码、文档、脚本、测试、公开 HotpotQA validation JSON、三份新模型原始评测记录、五份多轮工具协议诊断记录及示例工作区文件。它不包含 `.env`、SQLite 会话、`node_modules/`、`dist/` 或其他本地私有文件。恢复后先运行 `pnpm install && pnpm build`，再在本机准备 `.env`；复跑真实模型评测会调用并可能计费。旧会话不随压缩包恢复。
