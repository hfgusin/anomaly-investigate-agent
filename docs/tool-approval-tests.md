# 工具审批：共同验收清单

每一项先由用户在本机页面操作，再由系统记录 Run、工具状态和最终回答。测试输入只读取 `workspace/agent_demo.txt`，不使用业务数据。

| ID | 用户操作 | 页面预期 | 记录预期 |
|---|---|---|---|
| TA-1 | 请求读取文件，点「允许这次」 | 工具卡消失，最终回答 `Cedar-731` | `requested → approved → running → completed` |
| TA-2 | 请求读取文件，点「拒绝」 | 工具卡消失，模型说明不能读取 | `rejected`，结果不含文件内容 |
| TA-3 | 工具卡出现后刷新页面 | 刷新后仍显示同一张工具卡和两个决定按钮 | Run 保持 `running`，工具保持 `requested`；随后允许或拒绝可继续完成 |
| TA-4 | 工具卡出现后由 Gateway 重启 | 页面重连后该 Run 显示中断 | Run 和待审批工具都标为 `interrupted`；不读取文件，也不自动恢复执行 |

TA-1 至 TA-4 已由用户在真实接口下完成。自动化回归将覆盖对应的允许、拒绝与待审批任务终止语义。
